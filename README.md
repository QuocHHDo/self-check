# Should I Buy It?

Type a food and see its nutrition label plus a verdict (Get it / In moderation / Limit it / Skip) based on your own calorie, protein, saturated-fat, sodium, added-sugar and fiber goals.

- Single static `index.html`, no build step.
- Your goals are saved in your browser's local storage only.
- Nutrition values are approximate typical figures per serving; packaged foods vary by brand. General nutrition guidance, not medical advice.
